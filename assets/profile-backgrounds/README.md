# Profile backgrounds

Keep reusable card backgrounds here:

- `default/`: year-round images; `blackhole.png` is the current default.
- `halloween/`: October/Halloween.
- `winter/`: December/Christmas and winter.
- `pride/`: June/Pride.
- `spring/`: spring.
- `autumn/`: autumn.

PNG, JPEG, WebP and AVIF are supported by the renderer. The card crops to 1200 × 480, so wide artwork works best. Only the default is selected automatically today; these folders organize future seasonal artwork. No seasonal images or automatic seasonal switching were added in this change.
