# Offline Winter studies

These are experiments and simulation engines, not the current bot. Run them through the matching scripts in `scripts/winter/`.

- `early-progression.js`: early resource/combat studies.
- `chapter-simulation.js`: combined chapter/economy experiments.
- `chapter3-audit-model.js`: experimental later mechanics.
- `offline-checkpoints.js`: isolated SQLite checkpoint experiments.
- `discovery-window.js`: the historical proposed discovery gate, not the current seven-clue Brown system.
- `simulation-rng.js`: repeatable study random streams.

Inputs are in `config/winter/studies/`. Finished evidence retains its own frozen inputs under `artifacts/`; those snapshots were not moved or rewritten. Do not present an old result as a measurement of new rules.

For current gameplay, go to [../game/](../game/README.md).
